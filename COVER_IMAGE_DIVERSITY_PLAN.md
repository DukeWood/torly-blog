## Image Sources

### Option 1: Unsplash (Free, High-Quality)
- Professional business photos
- Technology and AI imagery
- UK landmarks and cities
- Startup and entrepreneurship scenes

### Option 2: Pexels (Free, High-Quality)
- Similar to Unsplash
- Good for business and tech imagery

### Option 3: AI Generation (if MCP available)
- Custom-generated images matching exact themes
- Consistent style across all images

## Implementation Strategy

1. **Search Unsplash/Pexels** for each theme
2. **Select images** that are visually distinct from each other
3. **Download at 1200px width** (WordPress featured image size)
4. **Upload to WordPress** media library
5. **Update post featured images** via WP-CLI or WordPress MCP
6. **Verify visual diversity** with browser test

## Success Criteria

✅ No two visible posts should have similar visual composition
✅ Each post should have a distinct, recognizable theme
✅ Images should be high-quality (1200px+ width)
✅ Images should relate to post content
✅ Visual variety improves blog engagement
